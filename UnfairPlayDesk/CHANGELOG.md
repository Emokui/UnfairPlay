# 更新日志

面向 Apple 芯片 Mac 的本机中文 IPA 工作台，最低部署目标为 macOS 14.0（macOS 14 实机验证待完成）。内置 ipatool 2.8.0-desk.9 和从固定版本源码编译的 UnfairPlay 引擎，不需要另外安装 Go 才能使用。

## 1.5.8

- 账户会话按档案使用 AES-256-GCM 加密。主程序从钥匙串读取主密钥后在本次运行期间复用。清除登录或删除档案会跳过损坏 Cookie 的解析并清理对应会话与 Cookie，防止损坏状态下无法清理账户；会话与文件锁拒绝符号链接路径。
- 查看登录状态只检查本地档案、加密会话与待迁移旧会话标识，已升级但尚未触发惰性迁移的账户会提示「旧版会话待首次使用时迁移」，未完成登录的档案显示「未登录」。等待密码或验证码时，工具可独立等待密钥请求，任务取消或退出时关闭通道。
- 改进登录与下载阶段的进度、超时和重试，复用认证组件及下载许可相关缓存。IPA 整理减少重复读取，远程图标下载与本机 IPA 图标提取统一限制在 8 MiB 内，图标获取失败时保留包内资源并继续处理。
- 本地 IPA 列表支持应用信息、搜索、状态筛选和账户模型匹配提示。下载记录可直接跳转到解密页，可按版本命名并保存到默认目录；下载、解密与验证完成后统一显示顶栏完成提示，单文件放弃保存时不再重复弹出批次汇总。
- 支持查看已保存的解密报告（同时核对标准化路径与文件 SHA-256 摘要）、导出脱敏诊断、按 Bundle ID 搜索、切换浅色或深色，以及检查 GitHub 正式版更新（区分尚无正式版、接口限流与网络异常，并在撤回正式版时清除旧提示）。
- 区分普通提示与故障诊断弹窗：普通通知不再附带诊断按钮，故障弹窗中复制详情或导出诊断不会关闭窗口或清空待重新登录与 App Store 跳转入口。保留导入清理、前置暂存及批量部分失败时的失败诊断与日志上下文，并严格过滤多行和截断 JSON 字段及转义路径/URL 脱敏。
- 内嵌工具使用固定签名标识符。修正 SAP 集成测试的资源清理顺序，消除授权桥接编译告警，并扩大账户会话、诊断脱敏、锁文件防御、更新检查、下载续传和模型相关的回归覆盖。

## 1.5.7 登录、下载和 IPA 状态修复

- 登录的运行库准备、账户认证和设备配置分别计时。SAP 请求限制响应体读取时间，重试等待支持取消。
- IPA 重打包在替换旧条目时保留正确的 ZIP 目录顺序。中断的文件传输可以按现有位置续传一次。
- IPA 状态扫描只读取通用二进制的架构表和各架构的 Mach-O 载入命令，支持超过 64 MiB 的通用二进制。取消扫描会同时结束后台任务。

## 1.5.2 输入弹窗和 IPA 下载列表

- 移除底部操作记录栏。密码和凭据库口令使用安全输入弹窗，双重认证验证码有独立的六位数字输入窗口。运行进度、取消按钮显示在页面标题右侧，失败弹窗保留具体错误。
- 搜索框右侧新增「已下载 IPA」，列出此版本起成功保存的文件。记录会在重启后保留；点击条目可在 Finder 中定位。已有文件可以通过「打开系统下载文件夹」查找。
- 模型初始化由主程序暂存用户选中的 IPA，再请系统授权，由辅助进程读取私有暂存副本，避免辅助进程直接打开 Downloads 时触发权限错误。原文件不变，任务结束后移除暂存副本。

## 1.5.1 登录与下载修复

- 合入 ipatool v2.8.1 的相关组件优化：ARM64 精简缓存、同进程组件与 Mach-O 解析复用，以及 4 MiB Unicorn JIT 缓冲上限；兼容已有组件缓存。
- 首次从 Apple 镜像提取时按需索引 AEA，显示组件与索引阶段；保留已读取的公共镜像元数据，失败后重试可以复用。顺序小块读取采用 256 KiB 预读，远程请求有 45 秒超时，整个冷准备最多 60 分钟。首次准备仍可能较慢，取决于 Apple CDN。
- 组件冷准备与下载票据计时分开；认证及票据阶段限制为 2 分钟，子步骤超时直接结束，不再静默转入无期限备用路径。Unicorn 运行库缺失时显示下载提示，保留原有下载超时。
- IPA、图标与远程 ZIP Range 读取使用直接 HTTP，无需启动 Apple 框架虚拟机。IPA 传输 45 秒无数据即结束连接，最多续传一次；活跃的大文件传输不设总时长限制。
- 去掉每次下载前重复的 `auth info`；下载命令读取账户时直接核对所选档案身份。免费应用缺少许可时仍自动获取，已购付费应用沿用原下载路径。
- 写入元数据、图标和 SINF 前过滤旧同名 ZIP 条目；下载与解密完成后的保存阶段保持忙碌状态，避免任务抢占。日志翻译缓存结果，跨块结构化消息不再因 8 KiB 阈值直接丢失。
- Apple 组件和运行库准备使用跨进程文件锁，避免重复写入。管理员授权改为系统 AppleScript 授权入口，继续通过流式输出显示初始化进度，不安装常驻服务。
- 保留原图标和现有浅色 UI；构建支持通过 `DESK_SIGNING_IDENTITY` 指定现有签名证书。默认 ad-hoc 签名在更新后仍可能要求重新授权钥匙串，未放宽凭据访问控制。

本版只执行编译和安装包生成，真实登录、下载、初始化与界面检查由用户完成；旧版验证记录不代表本版已完成这些实测。

## 1.5.0 应用搜索与历史版本

- 修复下载准备阶段长时间无提示：iOS 最新版直接请求下载票据，历史版保留指定版本；许可与会话错误直接处理，避免无效的备用接口及授权缓存重建。
- 下载 API、公共目录和许可请求使用 30 秒网络超时；本地验证准备完成后再启动票据请求计时，大文件传输不套用此时限。准备阶段分别显示下载配置、授权缓存、验证信息和下载地址，收到真实大小后才显示传输进度。
- 下载期间可切换页面、搜索应用、浏览版本和选择文件；只限制冲突的任务与账户修改。输入框仅在实际请求密码、验证码或凭据库口令时显示；搜索输入右侧新增清空按钮。
- 侧栏仅保留账户与模型、搜索与下载、解密与验证。账户页去除登录会话卡片，将账户头像、名称、Apple ID、模型状态及初始化收进同一卡片（初始化表单默认收起，保留应用与 IPA 选择和管理员授权流程）；查看状态和继续登录位于账户卡片右上角的三个点菜单，侧栏左下角使用浅色账户卡片（含头像、账户名、向上箭头与独立“＋”按钮），向上箭头展开固定在卡片上方的紧凑账户列表，点击外部收起。
- 搜索地区默认匹配已登录账户的 App Store 商店；账户缺失、已清除登录或地区不在选项中时默认美国。地区随登录和账户状态查询保存，旧档案首次进入搜索页只读取一次本地会话，不按 Apple ID 邮箱推断。仍可手动切换搜索地区。
- 移除 Agzy 源，加入 iOSDump；公共目录请求使用标准 JSON 请求头和本应用 User-Agent。
- 失败状态短暂显示约 5 秒后自动回到就绪；详细记录仍可查看。手动展开的日志保持打开，新任务会取消旧的收起计时。
- 全界面使用柔和的靛蓝配色、统一侧栏与宽松留白；账户切换集中在侧栏底部，账户、初始化和解密页面统一重做。各页面缩小标题、正文和图标尺寸；底部改为轻量任务状态栏，展开为浅底深字的日志面板，保留点击工作区收起与隐藏输入。下载采用“搜索结果 → 应用详情”两级浏览，避免同时堆叠多个面板。
- 下载页支持应用名称、App ID、App Store 链接搜索；使用紧凑且居中的搜索框，点击当前地区名称切换，无需先登录。结果显示图标、名称和开发者，选择应用后进入版本详情。
- 版本来源可手动选择 Timbrd、Bilin、iOSDump；公开来源只接收 App ID，Apple 账户密码和会话仍由原有独立档案管理。第三方仅提供版本索引，IPA 始终从 Apple 下载。
- 支持选取历史版本及直接输入版本 ID；手动输入版本 ID 时，可按需向 Apple 核对包内版本号和日期。版本记录不保证仍可下载；免费许可获取和已购付费应用下载规则保持一致。没有已登录账户时，下载按钮为浅色且不可用，搜索与版本浏览仍可使用。
- 搜索和公共版本查询使用异步请求，可取消；更换应用或账户时清除版本选择，避免串用旧版 ID。
- Swift、C、Go 工具统一按 macOS 14 部署目标重新编译，最低安装标识设为 14.0，目标覆盖 macOS 14、15、26、27，仍面向 Apple 芯片 Mac。编译与本机回归不等于所有系统实机验证；模型初始化仍依赖当前 FairPlay 格式及后续完整验证。
- [兼容性与本次验证记录](COMPATIBILITY.md) 说明各系统目标、验证范围和来源可用性。
- 搜索/版本浏览流程参考 [ipadn](https://github.com/mengangs/ipadn) 和 [Pastel-macOS](https://github.com/EEliberto/Pastel-macOS)，以现有账户与下载引擎独立实现。

## 1.3.9 免费应用许可

下载时自动尝试为当前 ID 获取免费应用许可，无需先在 iPhone 点“获取”。已有许可时直接下载；许可请求只使用零元价格，不自动购买付费应用。地区、账户验证、订阅或应用可用性限制仍由 Apple 决定，自动获取失败时可在系统 App Store 完成获取后重试。登录状态查询沿用 1.3.7 的账户信息查询流程，未采用已撤回的 1.3.8 元数据查询。

## 1.3.7 性能更新

- 下载时元数据、图标和个性化 SINF 一次写入最终 ZIP，保持未变成员的压缩字节，省去第二次整包重写。
- 默认初始化和仅验证共用完整的内存校验路径，不生成随后删除的完整 IPA；所有加密镜像仍需完成许可、解密及明文验证。手动 recover 与 setup --keep-work 仍保留诊断产物。验证结果不再输出不存在的解密 IPA 摘要。
- 同次账户登录的设备配置和账户验证共享 Apple 认证配置、机器身份，减少重复请求。
- 已解密二进制采用等级 3 DEFLATE，复用单个压缩器；未修改资源继续原样复制。1～4 页的小镜像顺序处理，大镜像继续并行。
- 增加初始化、登录、下载、解密阶段和耗时信息；整理 IPA 时清除旧下载百分比，解密显示镜像数量进度，保存记录实际耗时。
- 报告汇总真实的 plaintext_verified 状态，区分逐页哈希与结构审计，保留未验证 Apple CMS 签名的说明。

本机 M4 的公开 Apple 二进制压缩基准：等级 3 相比默认压缩由约 230 ms 降到 142 ms，压缩体积增加约 3.2%；不代表完整 IPA 的端到端提速比例。

## 1.3.6 混合代码与数据页面校验

移植上游 c1753f4076fceccbf3e97625ea88c0609869e978 的 CodeDirectory 加密前哈希解析。存在这张表时，对解密范围内每个签名页进行独立哈希匹配；任何不匹配都拒绝输出。没有加密前哈希时保留原来的 ARM64 结构审计和阈值。报告明确记录实际使用的校验方式及每张明文哈希表的匹配数量，不把哈希验证写成指令解码验证。

本地匿名 IPA 控制验证：45 个加密镜像、29004 页，所有镜像明文哈希匹配。没有执行其他账户或格式的完整私有控制矩阵。

## 1.3.5 首次组件提取性能

内核 ZIP 成员的固定约 33 MB 压缩数据一次读取后在内存中解压，避免解压器产生大量小块远程请求。保留 ZIP 大小与 CRC、内核结构以及最终组件 SHA-256 校验。认证缓存与 1.3.4 兼容。

## 1.3.4 本地认证更新

接入 ipatool 上游 001d889896fcb118546443c5dfe0997d11b74f56 的本地设备认证与 Store 配置流程。首次会提取新版本 Apple 认证组件，随后复用缓存；设备认证状态跟随账户 UUID 保存在同一独立钥匙串命名空间，并由清除登录一并移除。

Apple 返回 301/302/307/308 但没有 Location 时，使用现有三次请求上限，以 0.5 秒、1 秒间隔重新签名发送相同登录内容；保留 Cookie、验证码及认证地址。正常跳转和明确的账户/验证码响应不受影响，Retry-After 仍优先。持续异常时列出三次响应状态。本修复不保证解决 Apple 持续拒绝请求的情况，需用户实际登录验证。

## 1.3.3 操作流程修复

- 下载或解密完成后若保存失败，可当场另存到其他位置，无需重新处理；选择“放弃结果”后才清理临时结果。支持另存到其他磁盘，文件复制在后台执行且保存期间不启动重叠任务；解密报告记录最终保存路径。
- 导入源允许普通可读权限，复制到私有目录后仍设为 600 并完整校验；不修改源文件。
- 首次登录失败可在原档案继续登录，已填写的 ID 作为待登录提示保存，只有登录成功后的真实身份才会绑定。再次添加相同待登录 ID 时复用原档案。
- 认证阶段和等待密码/验证码在底部状态栏直接显示。空模型与数量超限分别提示，保留现有可折叠记录与页面结构。
- 构建默认从固定引擎源码编译；测试、打包支持显式应用路径，默认使用本次构建产物，未构建时使用 `/Applications/UnfairPlay.app`。完整第三方许可随包分发。

测试与打包指定应用的例子：`./test.sh /Applications/UnfairPlay.app`、`./package-dmg.sh /Applications/UnfairPlay.app`。

## 1.3.2 操作记录交互

点击底部状态栏可展开或收起操作记录，点击工作台其他区域自动收起；终端内部选择文字、滚动及交互输入保持正常，取消任务仍是独立按钮。任务开始时自动展开，密码与验证码输入栏不随记录折叠而隐藏。

## 1.3.1 首次认证提速

以下为 1.3.1 当时的实现记录，不代表现版组件读取方式。Apple 组件读取块从 128 KiB 改为 4 MiB，减少顺序提取时的网络往返；原有文件大小、摘要校验及共享缓存保留。认证日志增加缓存复用、下载提取、运行环境加载、建立连接等阶段。

本机使用隔离临时目录的实测：四个公开 Apple 认证组件首次准备 17.048 秒，缓存复用 19 毫秒；此数据不包含账户认证和验证码等待，不是所有网络环境的保证。模拟 16 MiB 顺序读取所需请求从 128 次降至 4 次。

“清除此账户登陆”清除本地登录凭据与 Cookie，保留模型和共享组件缓存。删除组件缓存不会强制触发 2FA，只会增加下一次准备耗时。Apple 是否要求验证码由服务端返回结果决定，本应用不支持强制触发。

## 1.3.0 界面与名称

应用名称统一为 UnfairPlay，使用新的薄荷绿 U 形图标。原生侧栏、统一账户切换、简化的文件选择卡片与可折叠操作记录；账户和模型的次要管理操作收进各自菜单。任务开始时自动展开记录，交互输入保持可见。支持系统浅色和深色外观。

账户数据目录、钥匙串服务和模型路径保持兼容，无需重新登录或初始化。

## 1.2.2 文件与状态修复

- 保存前检查输出目标是否在任务期间变化；新文件使用不覆盖的原子重命名，同名替换仍沿用系统保存对话框。
- 已校验的同名导入模型通过临时文件原子替换，支持修复已有损坏模型。
- 清除凭据成功后才标记待删除；失败或取消不再把正常档案锁入待删除状态。部分数据清理失败仍保留重试入口。
- 账户配置与目录识别断开的符号链接，报告读取/清理错误并保留档案，不再当作不存在而覆盖或误报删除成功。
- 模型缓存按文件元数据失效，不增加后台轮询或重复内容哈希；文件未变化时复用校验结果。

## 1.2.1 模型校验加速

常规模型状态检查和导入检查改用独立的 `modelcheck`，不再调用包含系统 FairPlay 扫描的完整 doctor。校验器直接调用 `InspectEnrollmentModel`，源码固定为与原有内置 UnfairPlay 二进制一致的 `41f064bfe0ef947e748b785b8ab62697a64bdbe6`，未改动解密、恢复、模型解析或布局支持策略。

保留文件与目录私有权限、普通文件及符号链接检查、数量与大小限制；仍由原始解析器检查模型封装、版本、布局和置换表。支持该解析器已支持的模型格式。无持久化“免校验”缓存，也不以仅有 .bin 后缀作为通过依据；原有进程内缓存保留。

本机相同真实模型只读对照：完整 doctor 12.697 秒；纯模型校验器首次 0.599 秒，后续 0.005–0.010 秒。上述为工具进程耗时，图形界面还包括资源签名检查和任务调度开销。模型内容未改变，损坏模型继续拒绝。

新增源码在 `Vendor/unfairplay/cmd/modelcheck`。该固定版本仓库的普通测试、vet 和竞态测试，以及工作台回归和软件包自检均执行；本次未运行完整私有恢复/砸壳矩阵，因为未修改主解密程序，仅作已有模型的只读解析对照。

## 1.2.0 验证记录

- C 回归：严格初始化参数、目标目录身份/权限、UUID 限制、SUDO 身份、固定工具摘要与签名、授权桥接受保护副本、篡改拒绝、真实子进程退出状态。
- Swift 回归：隐藏输入不回显、回调串联、失败退出、取消、UTF-8 跨块输出、私有 umask、父进程退出后的子任务终止、实际 Go term.ReadPassword 与验证码交互。
- 文件回归：符号链接/硬链接原文件保护、原子替换、最终权限 600、报告最终路径、模型删除后的报告归属、账户清理隔离。
- 存储回归：不可读/损坏配置写保护、外部修改保护、实例锁、身份不匹配与重复身份拒绝、待删除状态、账户选择切换。
- 临时任务回归：异常恢复、按账户清理、创建失败回收、不删除其他账户临时目录。
- 原有真实模型只读校验通过；合法外观头部但内容损坏的模拟模型被完整解析器拒绝。既有账户配置和模型内容未改变。
- Go appstore/cmd 测试、最终应用签名和软件包自检通过；修改内嵌可执行文件的软件包副本被实际拒绝运行。

没有自动执行真实账户登录、下载、清除登录或删除档案，也没有替用户输入管理员密码。因此新账号的验证码登录和管理员初始化仍需在实际授权时验证，不能把模拟测试当作已完成这些真实操作。
